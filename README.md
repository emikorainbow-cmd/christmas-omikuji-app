# 世界のクリスマス旅おみくじ
A Magical Christmas Journey

魔法のプレゼントボックスを開けると、世界13か国のどこかのクリスマスと、来年へのひとことが届くウェブアプリです。

## ファイル
- `index.html` … 画面の骨組み
- `styles.css` … 見た目
- `data.js` … 国・運勢・メッセージ・ラッキーアイテム・曲のデータ（ここを書きかえると内容を追加・修正できます）
- `art.js` … オリジナルのイラスト（運勢のマーク、スタンプなど）
- `app.js` … 動き・音楽・スタンプ帳などのしくみ
- `images/` … 場面の絵と各国の風景の絵

## 音楽
すべて著作権の切れた古い曲を、ブラウザの中で合成してオルゴール風に鳴らしています。音声ファイルは使っていません。
